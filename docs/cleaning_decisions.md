# قرارات تنظيف وتجهيز البيانات

تُنفّذ الفحوص التالية في خلية تحميل وتجهيز البيانات في [دفتر التحليل](../notebooks/analysis.ipynb). لا تُحذف السجلات بسبب الأسعار أو الطلبات الشاذة، ولا تُعدّل ملفات `data/raw/`.

| المشكلة | العدد / النسبة | القرار | السبب والمنطق التشغيلي |
| :--- | :--- | :--- | :--- |
| **سعر بيع أعلى من السعر الأساسي (`checkout_price > base_price`)** | 116,101 صف (25.43%) | الاحتفاظ بالسجلات؛ يُحسب `discount_pct` بالصيغة `(base_price - checkout_price) / base_price`، فتكون القيمة سالبة عندما يتجاوز سعر البيع السعر الأساسي. | لا يُفقد نحو ربع السجلات ولا تُشوّه السلسلة الزمنية للطلب. |
| **القيم المفقودة (`Missing Values`)** | 0 في بيانات التدريب والبيانات بعد الدمج | لا يوجد تعويض أو حذف | الفحص العددي يبيّن اكتمال القيم في البيانات المستخدمة. |
| **القيم المكررة (`Duplicates`)** | 0 مفتاح مكرر (`week`, `center_id`, `meal_id`) و0 صف مكرر في بيانات التدريب | لا يوجد حذف | التحقق من مفتاح سجل الطلب والصفوف الكاملة قبل التحليل. |
| **القيم الشاذة في الطلبات (`Outliers`)** | تُحسب في الدفتر بقاعدة 1.5×IQR؛ ويُطبع عددها وعدد السجلات التي تحمل مؤشر بريد ترويجي أو ظهور في الصفحة الرئيسية. | الاحتفاظ بها وعدم تطبيق فلتر عليها | قد تمثل ذروات تشغيلية مهمة. وجود مؤشر ترويجي لا يثبت وحده أن سبب القيمة الشاذة هو الترويج. |

بعد كل دمج أو فلترة في الدفتر، تُطبع أعداد الصفوف ومجاميع الطلبات. ويُطبع أيضًا عدد الصفوف ومجموع الطلبات لمجموعتي التدريب والتحقق؛ هذه التقسيمات لا تغيّر ملفات البيانات الخام.
